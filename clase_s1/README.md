# Clase S1 · Herramientas de Visualización de Datos

Material base para clase y para estudiantes.

## Contenido

### `notebooks/`
- `python_visual_vocabulary_gapminder.ipynb`
  Notebook de Python para explicar el caso paso a paso con `matplotlib`, `seaborn` y `plotly`.
- `r_visual_vocabulary_gapminder.Rmd`
  Notebook de R para explicar el mismo caso con `Base R`, `ggplot2` y `plotly`.

### `streamlit/`
- `app_demo.py`
  App de Streamlit para mostrar la versión interactiva del caso.
- `requirements.txt`
  Librerías de Python necesarias.

### `shiny/`
- `app_demo.R`
  App de Shiny para mostrar la versión interactiva del caso en R.
- `instalar_paquetes.R`
  Script para instalar paquetes de R necesarios.

### `docs/`
- `guia_ejecucion_estudiantes.md`
  Guía rápida para correr los materiales.
- `guia_codigo_python.md`
  Explicación del código de Python.
- `guia_codigo_r.md`
  Explicación del código de R.
- `ficha_proyecto.md`
  Ficha inicial de proyecto para estudiantes.

## Recomendación de uso en clase

1. Empezar con el notebook.
2. Mostrar la misma pregunta en varias librerías.
3. Cerrar con la app en Streamlit o Shiny.

## Caso de clase

Todos los materiales usan `Gapminder` para responder la misma pregunta:

> ¿Cómo ha cambiado el desarrollo humano entre 1952 y 2007, qué regiones avanzan más lento y dónde deberíamos mirar primero?
